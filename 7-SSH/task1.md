# Настриваем

1. Какой по умолчанию используется порт для поключения?
    порт 22

2. Можно ли его изменить? если да то как?
    Да, во-первых, нужно проверить доступность нового порта. После чего нужно открыть конфигурационный файл в ssh и в строке #Port 22 заменить номер порта на желаемый(предварительно раскомментировав строку)

3. Какая служба отвечает за обработку запросов на подключения по ssh?
    sshd

4. Какой файл конфигурации отвечает за его настройку?
    etc/openssh/sshd_config

    см. Картинку image_7_1_6

7. Измените колличество ошибок ввода пароля перед сборосом соединения, покажите эти измененения

10. Как вы это сделали?
    Дописал в конфиге строчку DenyUser ssh-user, тем самым запрещая вход этому пользователю

11. Что хранится в файле known_hosts?
    список публичных ключей всех хостов, к которым пользователь уже подключался.
