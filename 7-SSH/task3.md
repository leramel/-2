# Ключики

1. Что такое ssh ключи и зачем они нужны?
    SSH-ключ — это криптографический ключ, используемый для аутентификации и установления защищенного соединения между клиентом и сервером без необходимости ввода пароля.

2. Как их создать?
    командой ssh-keygen

3. Создайт пару публичный/приватный ключ ed_25519, где они хранятся?
    Приватный ключ хранится в ~/.ssh/id_ed25519, а публичный в ~/.ssh/id_ed25519.pub
    См. картинку image_7_3_3
4. Скопируйте публичный ключ на ваш сервер, в каком файле он будет храниться?
    ~/.ssh/authorized_keys
    см. картинку image_7_3_4

5. Попробуйте подключиться к серверу, у вас запросили пароль?
    Попробовал. На удивление нет, но в отдельном окне попросили ввести кодовую фразу для подключения.

6. Запретите подключение с паролем для всех пользователей, оставьте только с помощью ключа.
    В файле конфигурации в поле PasswordAuthentication нужно заменить исходное значение на no, а после сохранения файла перезапустить sshd
    cм. Картинку image_7_3_6
