# Перенаправляем

### 1) Как работают команды >,>>?
Операторы > и >> используются для перенаправления стандартного потока вывода (stdout).

">" — записывает вывод команды в файл, полностью заменяя его содержимое

">>" — добавляет вывод команды в конец файла, не удаляя старые данные

Пример:
```
echo "Первая строка" > data.txt
echo "Вторая строка" >> data.txt
```
### 2) Что такое перенаправление ввода? stderr,stdout;
stdout — стандартный поток вывода, куда программа отправляет результат своей работы

stderr — стандартный поток ошибок, используется для сообщений об ошибках

Перенаправление ввода — это механизм, позволяющий заменить стандартный ввод (stdin) данными из файла или другого источника.

Пример:
```
sort < data.txt
```
### 3) Выести содержание файла не используя текстовые редакторы;
```
cat data
```
### 4) Создать файл с содержимым не используя текстовые редактор;

echo "Здесь могла быть ваша реклама" > example.txt

### 5) пернеаправить stdout в stderr и обратно на примере команды kinit, ping, tracert

```
ping google.com 1>&2

ping nonexistent.host 2>&1
```

### 6) чем отличаются stdout и stderr
stdout используется для обычного вывода программы (данные, результаты)

stderr предназначен для сообщений об ошибках и предупреждений

### 7) что такое stdin?
stdin — стандартный поток ввода, через который программа получает данные
(клавиатура, файл, вывод другой команды).

Пример: 
```
wc -l < example.txt
```

### 8) как отправить весь вывод команды в пустоту?

```
ls unknown_dir > /dev/null 2>&1
```
