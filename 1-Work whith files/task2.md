# Перенаправляем

1. Как работают команды >,>>?
   Это команды перенаправления потоков вывода. При 

этом > может перезаписывать файл, >> добавлять данные в конец. Можно направлять стандартный поток вывода в файл.

> file - Если файл не существует, он будет создан, если существует - перезаписан сверху.

>> file - та же ситуация, но если файл есть - данные будут дописаны к нему в конец.



2\. Что такое перенаправление ввода? stderr,stdout;

stderr - стандартный вывод ошибок.

stdout - стандартный вывод.

перенаправление ввода - это возможность перенаправки стандартного ввода(stdin) в определенное место, например в файл



3\. Выести содержание файла не используя текстовые редакторы;

cat myfile

4\. Создать файл с содержимым не используя текстовые редактор;

cat > myfile1

5\. пернеаправить stdout в stderr и обратно на примере команды kinit, ping, tracert

ping blog.ru 1>\&2

ping blog.ru 2>\&1

6\. чем отличаются stdout и stderr

stdout и stderr - два разных потока. Один направляет успешный выход программы(stdout: результаты работы, данные, информация), 

а другой выходные ошибки(stderr: предупреждения, ошибки, отладочная информация)

7\. что такое stdin?

Стандартный поток ввода данных.

8\. как отправить весь вывод команды в пустоту?

cd 114 > /dev/null 2>\&1 (микропояснение: папки 114 в наших подкаталогах нет, поэтому для проверки можно выяснить, что поток ошибок тоже ушел в нулину)
