# Открываем firewald

1. Удалите iptables и установите firewalld
    сделано.

2. Попробуйте так-же проверить возможность подключения по ssh
    Тоже вошел без всяких проблем. Причем входил всеми возможными способами.

3. Если её нет то откройте порт
    сделаем это с помощью команды firewalld-cmd
    см. картинку image_9_2_3

4. Выведите список открытых портов с помощью firewall-cmd
    см. картинку image_9_2_4

5. Можно ли там добавить порты по названию сервиса?
    Да, можно.

6. На вашей Локальной виртуальной машине попробуйте подключиться к серверу samba из предыдущих заданий
    используем --add-service для подключения к samba через firewalld
    см. картинку image_9_2_6

7. Если не получилось то откройте нужные порты
    Всё получилось, спасибо за за совет :3

8. Сделайте так чтобы изменения были постоянными
    Для этого нужно использовать --permanent во вводимых командах firewall-cmd, а после перезагрузить правила с помощью --reload. тогда изменения сохранятся.
    см. Картинку image_9_2_8
