
# Открываем iptables

1. Установите iptables

    использовал команды:
    apt-get update
    apt-get install iptables

    Установил по итогу.

2. Проверьте осталась ли возможность подключения по ssh к вашему серверу
    Да, осталась.
3. Почему может пропасть такая возможность?
    Думаю это может случится, если для SSH порта нет разрешающего правила, утверждаемого политикой для входящих пакетов., по умолчанию(Input)., проблема будет если она будет изменена на DROP(сброс) или REJECT(отклонение)

4. Откройте нужный порт на сервере чтобы восстановить подключение
    для этого используем команду
    sudo iptables -A INPUT -p tcp --dport 201 -j ACCEPT

5. Это будет udp или tcp прот?
    tcp порт, т.к ssh использует именно его

# Сохраняем

6. Сохраняются ли записанные вами правила после перезагрузки?
    Нет, т.к всё что мы делаем в iptables сохраняется в оперативке, то бишь в течении одной сессии.

7. Как их сохранить?
    нужно использовать команду iptables-save, вывод которой будет перенаправляться в системный файл.
    см. картинку image_9_1_7

При работе с firewall не рекомендую отключаться от текущей сессии ssh. Лучше подключаться из другой консольки. (ладно :3)
