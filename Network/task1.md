
# сети

1. Выведите список интерфейсов, какими способами можно это сделать?
    ip link 
        Выводит список доступных сетевых интерфейсов. В выводе могут быть имена интерфейсов, MAC-адреса, текущее состояние и другая информация.
    netstat -i
        Показывает таблицу сетевых интерфейсов и статистику по передаче и приёму данных (байты, пакеты).
    ls /sys/class/net/
        Выводит простой список имён сетевых интерфейсов, присутствующих в этом каталоге

6. Что такое ip адрес?
    Уникальный числовой идентификатор устройства, подключённого к сети интернет или локальной сети.

7. Для чего нужны маршруты?
    Они определяют, куда направлять пакеты для определённых сетей: непосредственно в локальную сеть или через шлюз.

8. Что за протокол arp?
    Протокол в компьютерных сетях, предназначенный для определения MAC-адреса другого компьютера по известному IP-адресу.

9. Что такое dhcp?
    Сетевой протокол, позволяющий сетевым устройствам автоматически получать IP-адрес и другие параметры, необходимые для работы в сети TCP/IP.

10. Что такое dns?
    Распределённая компьютерная система, предназначенная для получения данных о доменах. Обычно она используется для определения IP-адреса по имени хоста (компьютера или устройства), получения информации о маршрутизации электронной почты и/или обслуживающих узлах для протоколов в домене (например, SRV-записи).

11. Как называется один из протоколов синхронизации времени?
    NTP

12. Что такое широковещательный запрос, зачем он нужен?
    Широковещательный запрос — это особый тип сетевого сообщения, которое отправляется одновременно всем устройствам в пределах определённого сегмента сети, необходимый для открытия arp, а также  для обнаружения соседей/служб, когда MAC/сервер неизвестен

13. Какой адресс является широковещательным?
    это IP адрес 255.255.255.255

14. Какие ещё параметры можно задать сетевой карте?
    Широковещательный адрес, MTU, MAC-адрес итп.

15. Что такое маска подсети? зачем она нужна?
    Маска подсети — это 32-битное число, двоичная запись которого
    содержит непрерывную последовательность единиц в тех разрядах,
    которые должны в IP-адресе интерпретироваться как номер сети. С их помощью
    можно задавать какое угодно число бит в номере узла.
