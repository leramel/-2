
# Запрещаем

### 1. Запретите пользователю user1 из предыдщуего задания выполнять вход в систему

sudo usermod -s /usr/sbin/nologin user1

### 2. Как вы это сделали?

Я изменил login-оболочку пользователя на специальную оболочку nologin,
которая запрещает интерактивный вход, но при этом учётная запись остаётся в системе.

### 3. Какие ещё способы это сделать вы знаете?

Блокировка пароля: 
```
sudo passwd -l user1
```
Отключение через файл /etc/shadow: 
```
sudo usermod -L user1
```
### 4. Можно ли создать пользователей с одинаковыми username?

Каждый username должен быть уникальным и Linux использует username как уникальный идентификатор, поэтому нет
