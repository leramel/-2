
# Запрещаем

1. Запретите пользователю user1 из предыдщуего задания выполнять вход в систему
    sudo usermod -L user1
2. Как вы это сделали?
    Cтрока зашифрованного пароля предваряется одним или двумя восклицательными знаками (!), что делает хранимый хеш пароля недействительным. В результате пользователь не может войти в систему.

3. Какие ещё способы это сделать вы знаете?
    Можно воспользоваться командой passwd, которая заблокирует учетную запись пользователя, не удаляя её.
    sudo passwd -l user1

4. Можно ли создать пользователей с одинаковыми username?
    Нет, нельзя. Username - уникальное значение. При создании второго пользователя с существующим в системе username произойдет ошибка.
