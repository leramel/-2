1. Добавление пользователей
1.1 Создание пользователя user1 с оболочкой bash
 ```
sudo useradd -m -s /bin/bash user1
 ```
1.2 Создание пользователя user2 с оболочкой sh
 ```
sudo useradd -m -s /bin/sh user2
 ```
1.3 Установка паролей
 ```
sudo passwd user1
sudo passwd user2
 ```

2. Назначение групп
Добавление user1 в группу администраторов
 ```
sudo usermod -aG sudo user1
 ```
 ```
groups user1
 ```

Добавление user2 в группу пользователя user1
 ```
sudo usermod -aG user1 user2
 ```
 ```
groups user2
 ```
3. Права доступа

Права доступа — это механизм Linux, определяющий, кто и какие действия может выполнять с файлом или директорией:

r — чтение

w — запись

x — выполнение

Права задаются для:

владельца

группы

остальных пользователей

Просмотр прав доступа в директории пользователя
 ```
ls -l
 ```
4. Изменение прав на файлы
Создание файла
 ```
touch all_access.txt
 ```

Назначение всех возможных прав для всех пользователей
 ```
chmod 777 all_access.txt
 ```


Проверка:
 ```

ls -l all_access.txt
 ```


Ожидаемый результат:

-rwxrwxrwx

5. Учётная запись встроенного администратора

Встроенная учётная запись администратора в Linux называется:

root

6. Выполнение команды от имени администратора
С помощью sudo
 ```
sudo command
 ```

Пример:
 ```
sudo ls /root
 ```
7. Ограничения суперпользователя

Суперпользователь (root) не имеет программных ограничений на уровне системы:

может управлять пользователями и группами

имеет доступ ко всем файлам

может изменять конфигурацию системы

Ограничения возможны только на уровне аппаратуры или ядра.

8. Удаление пользователя user2 с помощью пользователя user1

Переключение на user1:
 ```
su - user1

 ```
Удаление пользователя:
 ```
sudo userdel -r user2
 ```

Проверка:
 ```
id user2
 ```
9. Изменение владельца файла (папки)
Команда изменения владельца
chown

Изменение владельца файла из пункта 4
 ```
sudo chown user1:user1 all_access.txt
 ```

Проверка:
 ```
ls -l all_access.txt
 ```
