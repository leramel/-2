# Продолжаем

1. Raid массивы, что такое икакие бывают
    RAID (избыточный массив независимых дисков) – технология объединения нескольких дисков в единый логический элемент для избыточности и повышения производительности.

    RAID 0 — Данные распределяются блоками по всем дискам, операции выполняются параллельно, но отказ одного диска приводит к потере массива.

    RAID 1 — Создаёт полные копии данных на нескольких дисках. При отказе одного диск продолжает работать с копией, обеспечивая отказоустойчивость.

    RAID 5 — Использует минимум три диска с паритетом для защиты данных. При отказе одного диска данные восстанавливаются по паритету.

    RAID 6 — использование 4 или более дисков с проверкой P+Q или DP, защищающий от потери данных при отказе двух дисков.

    RAID 10 — Минимум четыре диска, комбинация RAID 0 и RAID 1, с зеркальным копированием данных.

6. В чём между ними разница?
    RAID 0 объединяет диски для увеличения скорости и емкости, без защиты данных. RAID 1 зеркалирует данные на два диска, обеспечивая их сохранность при отказе одного диска.
7. Есть ли файловые системы которые поддерживают raid массивы без стороненго ПО
    btrfs, zfs
8. Можно ли создать raid массив во время установки системы?
    Можно. При установке системы на этапе разметки дисков необходимо выбрать ручную разметку, создать RAID-массив, указать его тип, добавить физические диски в массив и оформить файловую систему на RAID-устройстве.
