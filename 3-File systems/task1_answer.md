# Файловая система

### 1.Какие файловые системы вы знаете?

ext4, XFS, Btrfs, F2FS, FAT32, NTFS, exFAT, APFS, HFS+, ZFS, tmpfs, procfs, NFS

### 2.Как можно классифицировать файловые системы? В чём основные отличия?

По типу хранения данных и назначению
1) Дисковые (ext4, XFS, NTFS) - поддерживают журналирование, права лоступа, работу с большими файлами
2) Для флешек (FAT32, exFAT) - совместимость со всеми ос, но нет поддержки прав доступа юникс и журналирования
3) Сетевые (NFS) - можно работать с файлами с другого компьютера
4) Виртуальные (tmpfs, procfs) - не занимают видео на жёстком диске, генерируются на лету и исчезают при выключении питания

### 3.Какие файловые системы обычно используются в Linux?

* ext4 - самая распространенная, по умолчанию во многих дистрибутивах
* XFS - часто по умолчанию в корпоративных дистрибутивах
* Btrfs - современная файловая системаб поддерживает снимки состояния, может сжимать данные на лету
* F2FS - оптимизирована для флешек

### 4.Как создать файловую систему на блочном устройстве?

Команда с указанием типа файловой системы и именем устройства
```shell
sudo mkfs.ext4 /dev/sdb1
```

### 5.Что такое монтирование и как подключить файловую систему в систему?
Монтирование - процесс присоединения файловой системы блочного устройства к определенному пустому каталогу в едином дереве файловой системы
```shell
sudo mount /dev/sdb1 /mnt
```
/dev/sdb1 - устройство
/mnt - каталог, где оно станет доступно

### 6.Рассмотрите procfs, sysfs, tmpfs и cifs. 6.1) В чём особенности каждой из них? 6.2) Найдите в своей системе каталоги, куда примонтированы эти файловые системы, если они используются.
* procfs (/proc) - виртуальная файловая система, предоставляет интерфейс к структурам данных ядра, содержит информацию о запущенных процессах и параметрах работы системы в реальном времени. Файлы не занимают место на диске, а генерируются при чтении
* sysfs (/sys) - виртуальная фс, которая экспортирует информацию об устройствах, драйверах и подсистемах ядра. Позволяет менять некоторые из них
* cifs - сетевая фс, используется в линукс для подключения к общим сетевым папкам, созданным в винде

  proc, sys примонтированы обязательно
  tmpfs - используется много где
