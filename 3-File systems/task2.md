# Струтура каталогов

1) Какая структура каталогов в linux? выведите список файлов в корне системы
    Древовидная структура.
    См. картинку image_3_2_1
2) Где хранятся папки пользователей в системе?
    в папке home/, находящейся в корневой папке
3) Где домашняя папка суперпользователя?
    /root/
4) Где хранятся основые конфигурационные файлы в системе?
    /etc/
5) ЧТо за папки /bin,/sbin,usr/sbin,/usr/sbin
    /bin - Содержит команды, которые могут использоваться как системным администратором, так и пользователями, но которые необходимы, когда не смонтированы никакие другие ФС.

    /sbin - Утилиты, используемые для системного администрирования (и другие команды только для root), /sbin содержит двоичные файлы, необходимые для загрузки, восстановления, восстановления и/или восстановления системы в дополнение к двоичным файлам в /bin.

    usr/sbin - содержит исполняемые файлы различных программ, которые не нужны на первых этапах загрузки системы

    /usr/sbin - тоже самое, что и предыдущее, но для использования администраторами.
