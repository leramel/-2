# Юниты

1. Что такое systemd юнит?
    Юнит (unit) в systemd — это конфигурационный файл, в котором описывается объект, управляемый systemd: служба, сокет, таймер, точка монтирования, устройство и другие ресурсы.

2. Проверье статус любого systemd юнита, какую информацию выводит эта кманда?
    systemctl status sshd
    см. картинку image_5_1_2

    Loaded — статус загрузки файла юнита (успешно — loaded). Также выводится путь к файлу.
    Active — текущее состояние юнита: если юнит запущен — active(running) (обычно), если не был запущен — inactive(dead).
    Docs — название man-страницы с документацией для службы.
    Process — запускаемые процессы, их состояние и код выхода.
    Main PID — ID основного процесса службы. (1170)
    Tasks — количество процессов, запущенных в рамках этой службы. (1)
    Memory — потребление памяти службой. (2.5M)
    CPU — использование процессора службой. (77ms)
    Журнал службы — последние 10 строк вывода основного процесса. Если нужно получить больше строк, используется опция --lines с нужным количеством строк.

3. ПОпробуйте оставновить сервис.
    systemctl stop sshd
    см. картинку image_5_1_3

4. Перезапустите его.
    systemctl restart sshd
    см. картинку image_5_1_4

5. УДалите из автозагрузки
    systemctl disable sshd
    см. картинку image_5_1_5
    
6. Верните обратно
    systemctl enable sshd
    см. картинку image_5_1_6

7. Что такое таймеры?
    Таймеры - это файлы, позволяющие запускать задачи по расписанию, отслеживать их состояние и интегрировать с системой сервисов.
