
# Шарим


1. Установите пакет samba
    установил

2. ЧТо такое побщая папка, зачем оно может быть нужно?
    Общая папка — это каталог, размещённый на сервере и доступный другим компьютерам в сети для чтения и/или записи. Она предназначена для централизованного хранения данных и обмена файлами между машинами в сети.

3. Создайте общую папку без пароля с правами только на чтение файлов
    после создания папки и установления прав, добавим в конфиге samba readonly для public
    см.картинку image_8_1_3

4. Создайте общую папку с паролем с правами на чтение и запись
    алгоритм тот же, но в конфиге добавляем в private readonly на no и авторизацию с помощью пароля
    см. картинку image_8_1_4

5. Создайте общую папку с доступом для какой-то группы с полными правами
    см. картинку image_8_1_5
    Ещё там нужно сделать рестарт smb через systemctl restart smb smb(рано отскринил прост)

6. Создайте общую папку в которой у одной группы будет полный доступ, а у другой только доступ на чтение.
Третья группа не должна иметь к ней доступа
    здесь:
    fulacs_group - группа у которой полные права(ну т.е все)
    read_only_group - группа "только для чтения"
    noacs_group - группа без прав
    добавим правила настройки для нескольких групп в конфиге
    см. картинку image_8_1_6
