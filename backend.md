## Билет 1.	Организация ввода-вывода в Python. f-строки  
1. Организация ввода данных в Python

    Ввод данных в Python осуществляется с помощью функции input().
    Функция input() считывает данные с клавиатуры и всегда возвращает строку типа str.

    Пример:
    ```python
    name = input("Введите имя: ")
    ```

    Если необходимо работать с числами, введённые данные нужно преобразовать в соответствующий тип с помощью функций int() или float():
    ```python
    age = int(input("Введите возраст: "))
    height = float(input("Введите рост: "))
    ```

    Для ввода нескольких значений, введённых в одной строке, используется метод `split()`:
    ```python
    a, b = map(int, input("Введите два числа: ").split())
    ```
2. Организация вывода данных в Python

    Вывод информации на экран осуществляется с помощью функции `print()`.

    Функция `print()` может выводить один или несколько объектов:
    ```python
    print("Привет", name)
    ```

    Основные параметры функции `print()`:

    sep — разделитель между выводимыми объектами (по умолчанию пробел);

    end — символ окончания строки (по умолчанию переход на новую строку).

    Пример:
    ```python
    print(1, 2, 3, sep=", ", end=".")
    ```
3. Форматирование строк в Python

    В Python существует несколько способов форматирования строк:

    конкатенация строк;

    метод str.format();

    f-строки.

    Наиболее современным и удобным способом являются f-строки, появившиеся в Python версии 3.6.

4. f-строки (formatted string literals)

    f-строки позволяют встраивать переменные и выражения непосредственно внутрь строк.
    Перед строкой ставится буква f, а значения указываются в фигурных скобках {}.

    Пример:
    ```python
    name = "Анна"
    age = 18
    print(f"Имя: {name}, возраст: {age}")
    ```

    В f-строках можно использовать:

    арифметические выражения:

    `print(f"Сумма: {a + b}")`


    вызовы функций:

    `print(f"Длина имени: {len(name)}")`

5. Форматирование данных в f-строках

    f-строки поддерживают форматирование чисел:

    количество знаков после запятой:
    ```python
    x = 3.14159
    print(f"{x:.2f}")
    ```

    выравнивание и ширину поля:

    `print(f"{x:10.2f}")`


    Это делает вывод данных более наглядным и удобным.

6. Преимущества f-строк

    краткий и понятный синтаксис;

    высокая читаемость кода;

    возможность использовать выражения и функции;

    более высокая производительность по сравнению с другими способами форматирования.

    Вывод

    Таким образом, ввод-вывод в Python реализуется с помощью функций input() и print(), а для форматированного вывода данных наиболее удобным и современным инструментом являются f-строки, которые позволяют легко и наглядно формировать текстовые сообщения и результаты вычислений.
## Билет 2. Типы данных в Python. Арифметические операции над целыми и вещественными числами.  

### 1. Типы данных в Python

Тип данных определяет, какие значения может хранить переменная и какие операции над ней допустимы.
Python является языком с **динамической типизацией**, то есть тип переменной определяется автоматически при присваивании значения.

Основные встроенные типы данных:

* `int` — целые числа (например: `-5`, `0`, `42`);
* `float` — вещественные числа (числа с плавающей точкой, например: `3.14`, `-0.5`);
* `str` — строки;
* `bool` — логический тип (`True`, `False`).

Для определения типа переменной используется функция `type()`:

```python
a = 10
b = 3.5
print(type(a), type(b))
```

---

### 2. Целые и вещественные числа

Тип `int` используется для представления целых чисел произвольной длины.
Тип `float` используется для представления вещественных чисел и имеет ограниченную точность, так как хранится в двоичном формате.

Пример:

```python
x = 7      # int
y = 2.0    # float
```

---

### 3. Арифметические операции в Python

Python поддерживает стандартные арифметические операции над целыми и вещественными числами:

| Операция              | Обозначение | Пример   |
| --------------------- | ----------- | -------- |
| Сложение              | `+`         | `5 + 3`  |
| Вычитание             | `-`         | `5 - 3`  |
| Умножение             | `*`         | `5 * 3`  |
| Деление               | `/`         | `5 / 2`  |
| Целочисленное деление | `//`        | `5 // 2` |
| Остаток от деления    | `%`         | `5 % 2`  |
| Возведение в степень  | `**`        | `2 ** 3` |

---

### 4. Особенности арифметических операций

* Операция `/` **всегда возвращает вещественное число**, даже если деление выполняется без остатка:

```python
5 / 2    # 2.5
6 / 2    # 3.0
```

* Операция `//` выполняет целочисленное деление:

```python
5 // 2   # 2
```

* Операция `%` возвращает остаток от деления:

```python
5 % 2    # 1
```

* Возведение в степень:

```python
2 ** 3   # 8
```

---

### 5. Смешанные арифметические операции

При выполнении операций между `int` и `float` результат будет иметь тип `float`:

```python
5 + 2.5   # 7.5
```

Это связано с автоматическим приведением типов.

---

### 6. Приоритет арифметических операций

В Python соблюдается стандартный порядок выполнения операций:

1. `**`
2. `*`, `/`, `//`, `%`
3. `+`, `-`

Для изменения порядка вычислений используются круглые скобки:

```python
(5 + 3) * 2
```

---

### Вывод

Таким образом, Python поддерживает различные типы данных, среди которых важное место занимают целые (`int`) и вещественные (`float`) числа. Над ними можно выполнять стандартные арифметические операции, соблюдая правила приоритета и автоматического приведения типов, что делает язык удобным для математических вычислений.
## Билет 3. Тип decimal  
### 1. Назначение типа `decimal`

Тип `decimal` в Python используется для **точных вещественных вычислений**, когда недопустимы ошибки округления, характерные для типа `float`.
Он особенно важен в финансовых, бухгалтерских и научных расчётах, где требуется высокая точность.

Тип `decimal` реализован в стандартном модуле `decimal`.

---

### 2. Причины использования `decimal`

Вещественные числа типа `float` хранятся в двоичном формате, из-за чего некоторые десятичные дроби не могут быть представлены точно.

Пример проблемы с `float`:

```python
0.1 + 0.2   # 0.30000000000000004
```

Тип `decimal` хранит числа **в десятичном виде**, что позволяет избежать подобных ошибок:

```python
from decimal import Decimal

Decimal('0.1') + Decimal('0.2')   # Decimal('0.3')
```

---

### 3. Создание объектов типа `Decimal`

Объекты `Decimal` создаются с помощью класса `Decimal`.
Рекомендуется передавать число **в виде строки**, чтобы сохранить точность.

Пример:

```python
from decimal import Decimal

a = Decimal('10.25')
b = Decimal('2.5')
```

Создание `Decimal` из `float` нежелательно, так как ошибка округления уже присутствует:

```python
Decimal(0.1)  # неточное значение
```

---

### 4. Арифметические операции с `Decimal`

Тип `Decimal` поддерживает основные арифметические операции:

* сложение `+`
* вычитание `-`
* умножение `*`
* деление `/`
* возведение в степень `**`

Пример:

```python
a = Decimal('5.5')
b = Decimal('2')

a + b
a * b
a / b
```

Все операции выполняются с высокой точностью.

---

### 5. Контекст вычислений

Модуль `decimal` позволяет управлять:

* точностью вычислений;
* правилами округления.

Контекст задаётся с помощью функции `getcontext()`:

```python
from decimal import getcontext

getcontext().prec = 4
```

Пример:

```python
Decimal('1') / Decimal('3')   # результат с заданной точностью
```

---

### 6. Сравнение `float` и `Decimal`

| Характеристика     | `float`          | `decimal`               |
| ------------------ | ---------------- | ----------------------- |
| Точность           | Ограниченная     | Высокая                 |
| Представление      | Двоичное         | Десятичное              |
| Скорость           | Быстрее          | Медленнее               |
| Область применения | Общие вычисления | Финансы, точные расчёты |

---

### Вывод

Тип `decimal` предназначен для точных десятичных вычислений и позволяет избежать ошибок округления, характерных для типа `float`. Он используется в задачах, где важна точность результатов, и предоставляет гибкие средства управления точностью и округлением.

## Билет 4. Организация ветвления в Python. Логические операции  
### 1. Понятие ветвления

Ветвление — это механизм управления ходом выполнения программы, при котором в зависимости от выполнения логического условия выбирается одна из нескольких возможных ветвей выполнения.

В Python ветвление реализуется с помощью условного оператора `if`.

---

### 2. Условный оператор `if`

Базовая форма условного оператора:

```python
if условие:
    блок_кода
```

Если условие истинно (`True`), выполняется блок кода с отступом.

---

### 3. Оператор `if-else`

Для выбора между двумя вариантами используется конструкция `if-else`:

```python
if условие:
    блок_кода_1
else:
    блок_кода_2
```

---

### 4. Множественное ветвление `if-elif-else`

Для проверки нескольких условий используется конструкция `if-elif-else`:

```python
if условие1:
    блок_кода_1
elif условие2:
    блок_кода_2
else:
    блок_кода_3
```

Условия проверяются последовательно, и выполняется только первая истинная ветвь.

---

### 5. Логические выражения и операции сравнения

Условия в операторе `if` формируются с помощью операций сравнения:

* `>` — больше
* `<` — меньше
* `>=` — больше или равно
* `<=` — меньше или равно
* `==` — равно
* `!=` — не равно

Пример:

```python
if x > 0:
    print("Число положительное")
```

---

### 6. Логические операции

Python поддерживает три логические операции:

* `and` — логическое И;
* `or` — логическое ИЛИ;
* `not` — логическое НЕ.

Примеры:

```python
x > 0 and x < 10
x < 0 or x > 100
not (x == 0)
```

---

### 7. Таблица истинности логических операций

**Операция `and`:**

* `True and True` → `True`
* `True and False` → `False`

**Операция `or`:**

* `False or True` → `True`
* `False or False` → `False`

**Операция `not`:**

* `not True` → `False`
* `not False` → `True`

---

### 8. Логический тип данных `bool`

Результатом логических выражений является значение логического типа `bool`, которое может принимать значения `True` или `False`.

Пример:

```python
result = x > 5
print(type(result))  # <class 'bool'>
```

---

### 9. Вложенные условия

В Python допускается вложенность условных операторов:

```python
if x >= 0:
    if x == 0:
        print("Ноль")
    else:
        print("Положительное число")
```

---

### Вывод

Таким образом, ветвление в Python реализуется с помощью условных операторов `if`, `elif` и `else`, а логические операции `and`, `or` и `not` позволяют составлять сложные условия. Это даёт возможность управлять логикой программы в зависимости от различных условий.
## Билет 5. Цикл с параметром. break, continue  
### 1. Цикл с параметром в Python

В Python цикл с параметром реализуется с помощью оператора `for`.
Он используется для повторения блока кода определённое количество раз или для перебора элементов последовательности (списков, строк, диапазонов и т.д.).

Синтаксис цикла `for` с функцией `range()`:

```python
for i in range(начало, конец, шаг):
    блок_кода
```

* `начало` — первое значение (по умолчанию 0)
* `конец` — предел, до которого выполняется цикл (не включая его)
* `шаг` — приращение (по умолчанию 1)

Пример:

```python
for i in range(1, 6):
    print(i)  # Выведет числа от 1 до 5
```

---

### 2. Оператор `break`

`break` используется для **немедленного выхода из цикла**, даже если условие цикла ещё выполняется.

Пример:

```python
for i in range(1, 10):
    if i == 5:
        break
    print(i)
# Выведет 1, 2, 3, 4
```

---

### 3. Оператор `continue`

`continue` используется для **пропуска оставшейся части тела цикла** и перехода к следующей итерации.

Пример:

```python
for i in range(1, 6):
    if i == 3:
        continue
    print(i)
# Выведет 1, 2, 4, 5
```

---

### 4. Особенности использования `break` и `continue`

* `break` полностью завершает текущий цикл;
* `continue` прекращает только текущую итерацию, но цикл продолжается;
* Можно использовать в любых типах циклов (`for` и `while`).

Пример с условием:

```python
for i in range(1, 11):
    if i % 2 == 0:
        continue  # пропустить чётные числа
    if i > 7:
        break     # остановить цикл
    print(i)
# Выведет 1, 3, 5, 7
```

---

### Вывод

Цикл с параметром (`for`) позволяет выполнять повторяющиеся действия по заранее определённому числу шагов.
Операторы `break` и `continue` дают возможность контролировать выполнение цикла: `break` — досрочно завершить цикл, `continue` — пропустить текущую итерацию и перейти к следующей.
Эти инструменты делают управление циклом гибким и удобным.
## Билет 6. Цикл по условию. Морж

### 1. Цикл по условию в Python

Цикл по условию реализуется с помощью оператора `while`.
Он выполняет блок кода **до тех пор, пока заданное логическое условие истинно (`True`)**.

Синтаксис:

```python
while условие:
    блок_кода
```

Пример:

```python
i = 1
while i <= 5:
    print(i)
    i += 1
# Выведет числа от 1 до 5
```

Особенности:

* Проверка условия происходит **перед каждой итерацией**;
* Если условие сразу ложно, тело цикла не выполнится ни разу;
* Для предотвращения бесконечного цикла важно корректно изменять переменные, участвующие в условии.

---

### 2. Оператор «морж» (`:=`)

Оператор `:=` появился в Python 3.8 и называется **оператором присваивания выражения** или «морж».
Он позволяет **присвоить значение переменной прямо в выражении**, включая условие цикла.

Синтаксис:

```python
переменная := выражение
```

---

### 3. Использование «моржа» в циклах

Пример с циклом `while` для ввода чисел:

```python
from random import randint

# Генерация случайных чисел до появления числа 5
while (x := randint(1, 10)) != 5:
    print(x)
```

Объяснение:

* `(x := randint(1, 10))` — генерируем случайное число и одновременно присваиваем его переменной `x`;
* `!= 5` — условие для продолжения цикла;
* Цикл завершится, когда сгенерируется число 5.

Преимущества оператора «морж»:

* уменьшает количество строк кода;
* позволяет **одновременно вычислять и присваивать значение в условии**.

---

### 4. Другие примеры применения «моржа»

**Чтение данных до пустой строки:**

```python
while (line := input("Введите текст: ")) != "":
    print(f"Вы ввели: {line}")
```

**Суммирование чисел до отрицательного:**

```python
total = 0
while (num := int(input("Введите число: "))) >= 0:
    total += num
print("Сумма:", total)
```

---

### 5. Вывод

* **Цикл по условию (`while`)** используется для повторения блока кода, пока условие истинно.
* **Оператор «морж» (`:=`)** позволяет **присваивать переменные прямо в выражениях**, что делает код компактнее и удобнее, особенно при циклах и вводе данных.
## Билет 7. Списки в Python. Функции и методы.
**Ответ на экзаменационный билет**
**Тема: Списки в Python. Функции и методы**

---

### 1. Понятие списка

Список (`list`) — это **упорядоченная изменяемая коллекция элементов** произвольного типа.
Списки позволяют хранить несколько значений в одной переменной.

Пример:

```python
numbers = [1, 2, 3, 4, 5]
names = ["Анна", "Борис", "Виктор"]
mixed = [1, "два", 3.0, True]
```

Особенности списков:

* элементы имеют **порядок**, доступ по индексу;
* допускаются **дубликаты**;
* список **изменяемый** (можно добавлять, удалять, менять элементы).

---

### 2. Индексация и срезы

* Индексация начинается с 0:

```python
print(numbers[0])  # 1
```

* Отрицательные индексы обращаются с конца:

```python
print(numbers[-1])  # 5
```

* Срезы позволяют получить часть списка:

```python
print(numbers[1:4])  # [2, 3, 4]
```

---

### 3. Основные операции со списками

* Объединение списков: `+`
* Повторение элементов: `*`
* Проверка элемента: `in`
* Длина списка: `len()`

Пример:

```python
a = [1, 2]
b = [3, 4]
print(a + b)  # [1, 2, 3, 4]
print(a * 2)  # [1, 2, 1, 2]
print(3 in b) # True
print(len(a)) # 2
```

---

### 4. Методы списков

Списки обладают встроенными методами для изменения и обработки данных:

| Метод          | Назначение                                                    | Пример                      |
| -------------- | ------------------------------------------------------------- | --------------------------- |
| `append(x)`    | добавить элемент в конец                                      | `numbers.append(6)`         |
| `insert(i, x)` | вставить элемент на позицию i                                 | `numbers.insert(2, 10)`     |
| `remove(x)`    | удалить первый встреченный элемент x                          | `numbers.remove(2)`         |
| `pop([i])`     | удалить и вернуть элемент по индексу (по умолчанию последний) | `numbers.pop()`             |
| `clear()`      | удалить все элементы                                          | `numbers.clear()`           |
| `index(x)`     | индекс первого вхождения                                      | `numbers.index(3)`          |
| `count(x)`     | количество вхождений                                          | `numbers.count(2)`          |
| `sort()`       | сортировка списка                                             | `numbers.sort()`            |
| `reverse()`    | изменить порядок элементов на обратный                        | `numbers.reverse()`         |
| `copy()`       | создать копию списка                                          | `new_list = numbers.copy()` |

---

### 5. Встроенные функции для списков

* `len(list)` — длина списка
* `sum(list)` — сумма чисел в списке
* `min(list)` / `max(list)` — минимальное/максимальное значение
* `sorted(list)` — возвращает **отсортированную копию** списка

Пример:

```python
numbers = [3, 1, 4, 2]
print(len(numbers))   # 4
print(sum(numbers))   # 10
print(min(numbers))   # 1
print(max(numbers))   # 4
print(sorted(numbers)) # [1, 2, 3, 4]
```

---

### 6. Изменяемость списка

Списки изменяемы, поэтому операции типа `append`, `remove`, `sort` **модифицируют исходный список**, а `sorted()` возвращает новый.

---

### 7. Вывод

Списки — это универсальный и удобный способ хранения коллекций данных.
Методы и функции позволяют:

* добавлять и удалять элементы;
* находить элементы и их количество;
* сортировать и обрабатывать данные.

Правильное использование списков делает код более компактным и читаемым.
## Билет 8. Строки в Python. Функции и методы.
### 1. Понятие строки

Строка (`str`) — это **неизменяемая последовательность символов**, используемая для хранения текста.
Строки заключаются в одинарные `'...'`, двойные `"..."` или тройные кавычки для многострочного текста `'''...'''` или `"""..."""`.

Примеры:

```python
s1 = "Привет"
s2 = 'Python'
s3 = """Многострочный
текст"""
```

Особенности:

* **Неизменяемость** — нельзя изменить отдельный символ строки; можно только создать новую строку;
* **Индексация** и **срезы** работают так же, как и со списками.

---

### 2. Индексация и срезы

* Индексация начинается с 0:

```python
s = "Python"
print(s[0])   # 'P'
```

* Отрицательная индексация:

```python
print(s[-1])  # 'n'
```

* Срезы позволяют получить часть строки:

```python
print(s[1:4])  # 'yth'
print(s[:3])   # 'Pyt'

```

---

### 3. Операции со строками

* **Конкатенация** (сложение строк): `+`
* **Повторение строки**: `*`
* **Проверка вхождения**: `in` / `not in`
* **Длина строки**: `len()`

Пример:

```python
s1 = "Hello"
s2 = "World"
print(s1 + " " + s2)  # 'Hello World'
print(s1 * 3)          # 'HelloHelloHello'

print(len(s2))         # 5
```

---

### 4. Основные методы строк

Строки имеют множество встроенных методов для обработки текста:

| `title()`                                 | заглавные первые буквы всех слов                | `"hello world".title()` → `'Hello World'` |

| `find(sub)`                               | найти индекс подстроки, -1 если нет             | `"abc".find("b")` → 1                     |
| `count(sub)`                              | количество вхождений подстроки                  | `"aba".count("a")` → 2                    |
| `startswith(prefix)` / `endswith(suffix)` | проверка начала/конца                           | `"abc".startswith("a")` → True            |

---

### 5. Форматирование строк

* **f-строки (Python 3.6+)**:

```python
name = "Анна"
```

```python
print("Имя: {}, возраст: {}".format(name, age))
```

### 6. Функции для строк

* `min(s)` / `max(s)` — минимальный/максимальный символ (по Unicode)


### 7. Особенности строк

* **Неизменяемость**: любые операции создают новую строку;
* Методы строк **не изменяют исходную строку**, а возвращают новую;
* Строки можно использовать как **последовательности** для перебора в циклах.

---

### 8. Вывод

Строки — это основной тип данных для работы с текстом.
Богатый набор методов и функций позволяет:

* изменять регистр,
* обрезать пробелы,

## Билет 9. Множества в Python. Функции и методы.  

### 1. Понятие множества

Множество (`set`) — это **неупорядоченная коллекция уникальных элементов**.
Каждый элемент может встречаться **только один раз**, а порядок хранения не гарантируется.

Примеры:

```python
s = {1, 2, 3, 4}
s2 = set([1, 2, 2, 3])  # {1, 2, 3}
```

Особенности:

* **Уникальность элементов** — дубликаты удаляются;
* **Неупорядоченность** — элементы нельзя получить по индексу;
* Поддерживает только **хешируемые объекты** (например, числа, строки, кортежи).

---

### 2. Создание множеств

1. С помощью фигурных скобок `{}`:

```python
s = {1, 2, 3}
```

2. С помощью функции `set()` (из последовательности):

```python
s = set([1, 2, 2, 3])  # {1, 2, 3}
```

3. Пустое множество создаётся только через `set()`:

```python
s = set()
```

---

### 3. Основные операции с множествами

| Операция     | Описание                            | Пример          |
| ------------ | ----------------------------------- | --------------- |
| `in`         | проверка принадлежности             | `3 in s` → True |
| `len(s)`     | количество элементов                | `len(s)` → 3    |
| `add(x)`     | добавить элемент                    | `s.add(4)`      |
| `remove(x)`  | удалить элемент (ошибка, если нет)  | `s.remove(2)`   |
| `discard(x)` | удалить элемент без ошибки          | `s.discard(5)`  |
| `pop()`      | удалить и вернуть случайный элемент | `s.pop()`       |
| `clear()`    | очистить множество                  | `s.clear()`     |

---

### 4. Математические операции над множествами

Множества поддерживают стандартные операции теории множеств:

| Операция                     | Описание                     | Пример                             |        |                  |
| ---------------------------- | ---------------------------- | ---------------------------------- | ------ | ---------------- |
| `union` / `|`                | `|`                          | объединение                        | `{1,2} | {2,3}`→`{1,2,3}` |
| `intersection` / `&`         | пересечение                  | `{1,2} & {2,3}` → `{2}`            |        |                  |
| `difference` / `-`           | разность                     | `{1,2,3} - {2,3}` → `{1}`          |        |                  |
| `symmetric_difference` / `^` | симметрическая разность      | `{1,2} ^ {2,3}` → `{1,3}`          |        |                  |
| `issubset`                   | проверка подмножества        | `{1,2}.issubset({1,2,3})` → True   |        |                  |
| `issuperset`                 | проверка надмножества        | `{1,2,3}.issuperset({2,3})` → True |        |                  |
| `isdisjoint`                 | не пересекаются ли множества | `{1,2}.isdisjoint({3,4})` → True   |        |                  |

---

### 5. Функции для множеств

* `len(s)` — количество элементов;
* `min(s)` / `max(s)` — минимальный/максимальный элемент;
* `set()` — создание множества из последовательности;
* `sorted(s)` — возвращает **отсортированный список элементов множества**.

Пример:

```python
s = {3, 1, 4}
print(len(s))       # 3
print(min(s))       # 1
print(max(s))       # 4
print(sorted(s))    # [1, 3, 4]
```

---

### 6. Применение множеств

* Удаление дубликатов из последовательности:

```python
lst = [1, 2, 2, 3]
unique = set(lst)  # {1, 2, 3}
```

* Математические операции: объединение, пересечение, разность множеств;
* Проверка принадлежности элементов, эффективное хранение уникальных значений.

---

### 7. Вывод

Множества в Python — это удобный инструмент для работы с **уникальными элементами**.
Методы и операции над множествами позволяют:

* объединять и пересекать коллекции,
* находить разности и симметрические разности,
* эффективно проверять наличие элемента.

## Билет 10. Словари Python. Функции и методы.  

### 1. Понятие словаря

Словарь (`dict`) — это **неупорядоченная коллекция пар «ключ: значение»**.
Каждый элемент словаря состоит из:

* **ключа** (key) — уникальный и неизменяемый объект (`str`, `int`, `tuple` и др.);
* **значения** (value) — объект любого типа.

Пример словаря:

```python
student = {"name": "Анна", "age": 18, "grade": 5}
```

Особенности:

* Ключи **уникальны**, значения могут повторяться;
* Словарь **изменяемый**, можно добавлять, изменять и удалять элементы.

---

### 2. Доступ к элементам словаря

* Доступ по ключу:

```python
print(student["name"])  # Анна
```

* Безопасный способ с методом `get()`:

```python
print(student.get("surname", "Не указано"))  # Не указано
```

* Изменение значения:

```python
student["age"] = 19
```

* Добавление новой пары:

```python
student["city"] = "Москва"
```

---

### 3. Основные методы словарей

| Метод               | Описание                                          | Пример                                                                   |
| ------------------- | ------------------------------------------------- | ------------------------------------------------------------------------ |
| `keys()`            | возвращает список ключей                          | `student.keys()` → dict_keys(['name','age','grade'])                     |
| `values()`          | возвращает список значений                        | `student.values()` → dict_values(['Анна', 19, 5])                        |
| `items()`           | возвращает пары ключ-значение                     | `student.items()` → dict_items([('name','Анна'),('age',19),('grade',5)]) |
| `get(key, default)` | получить значение по ключу без ошибки             | `student.get('surname', 'Не указано')`                                   |
| `pop(key)`          | удалить элемент по ключу и вернуть значение       | `student.pop('grade')` → 5                                               |
| `popitem()`         | удалить и вернуть последнюю добавленную пару      | `student.popitem()`                                                      |
| `update(dict2)`     | добавить или обновить элементы из другого словаря | `student.update({"age":20, "city":"СПб"})`                               |
| `clear()`           | удалить все элементы                              | `student.clear()`                                                        |
| `copy()`            | создать копию словаря                             | `new_dict = student.copy()`                                              |

---

### 4. Встроенные функции для словарей

* `len(d)` — количество пар ключ-значение;
* `min(d)` / `max(d)` — минимальный/максимальный ключ по значению;
* `dict()` — создание словаря из последовательности пар или ключей с одинаковым значением.

Пример:

```python
d = dict.fromkeys(["a", "b", "c"], 0)  # {'a':0, 'b':0, 'c':0}
```

---

### 5. Перебор словаря

* По ключам:

```python
for key in student:
    print(key, student[key])
```

* По ключам и значениям:

```python
for key, value in student.items():
    print(key, value)
```

* По значениям:

```python
for value in student.values():
    print(value)
```

---

### 6. Применение словарей

Словари удобны, когда нужно:

* хранить пары ключ-значение;
* быстро находить значение по ключу;
* реализовывать частотные словари, справочники, конфигурации и базы данных в памяти.

---

### 7. Вывод

Словари в Python — это мощная структура данных для хранения и управления **парными данными**.
Методы словарей позволяют:

* получать ключи, значения и пары;
* добавлять, изменять и удалять элементы;
* безопасно работать с отсутствующими ключами.

Словари часто применяются для реализации ассоциативных массивов и быстрых поисковых структур.

## Билет 11. Работа с текстовыми файлами Python.  

### 1. Понятие текстового файла

Текстовый файл — это файл, который содержит данные в виде **текста**, читаемого человеком.
Каждая строка текста отделяется символом перевода строки `\n`.

Примеры текстовых файлов: `.txt`, `.csv`, `.log`.

---

### 2. Открытие файла

В Python для работы с файлами используется функция `open()`:

```python
file = open("example.txt", mode, encoding="utf-8")
```

* `"r"` — чтение (read, по умолчанию);
* `"w"` — запись (write, создаёт новый файл или очищает существующий);
* `"a"` — добавление (append, сохраняет существующие данные и добавляет новые);
* `"x"` — создание нового файла, если уже существует — ошибка;
* `"encoding"` — кодировка файла (часто `"utf-8"`).

---

### 3. Чтение файла

1. **Чтение всего файла**:

```python
with open("example.txt", "r", encoding="utf-8") as f:
    text = f.read()
```

2. **Построчное чтение**:

```python
with open("example.txt", "r", encoding="utf-8") as f:
    for line in f:
        print(line.strip())
```

3. **Чтение списка строк**:

```python
with open("example.txt", "r", encoding="utf-8") as f:
    lines = f.readlines()  # возвращает список строк
```

> Примечание: `with` используется для **автоматического закрытия файла**, даже если произойдет ошибка.

---

### 4. Запись в файл

1. **Запись новой информации** (перезапись файла):

```python
with open("example.txt", "w", encoding="utf-8") as f:
    f.write("Привет, мир!\n")
```

2. **Добавление в файл**:

```python
with open("example.txt", "a", encoding="utf-8") as f:
    f.write("Новая строка\n")
```

3. **Запись нескольких строк**:

```python
lines = ["Первая строка\n", "Вторая строка\n"]
with open("example.txt", "w", encoding="utf-8") as f:
    f.writelines(lines)
```

---

### 5. Основные методы работы с файлами

| Метод                       | Описание                                                |
| --------------------------- | ------------------------------------------------------- |
| `read(size)`                | чтение указанного количества символов                   |
| `readline()`                | чтение одной строки                                     |
| `readlines()`               | чтение всех строк в список                              |
| `write(text)`               | запись текста в файл                                    |
| `writelines(list_of_lines)` | запись списка строк                                     |
| `close()`                   | закрытие файла (необязательно при использовании `with`) |

---

### 6. Применение текстовых файлов

* хранение данных между запусками программы;
* обработка логов, конфигураций, отчетов;
* работа с CSV, JSON (часто как текстовые файлы);
* чтение больших текстов по строкам для анализа.

---

### 7. Вывод

Работа с текстовыми файлами в Python осуществляется через функцию `open()` и методы `read`, `write`, `readlines`, `writelines`.
Использование конструкции `with` делает работу с файлами безопасной и удобной, автоматически закрывая файл.
Файлы позволяют сохранять и загружать данные, работать с текстовой информацией и обеспечивают долговременное хранение данных.

## Билет 12. Работа с файлами csv в Python.
### 1. Понятие CSV-файла

CSV (Comma-Separated Values — значения, разделённые запятыми) — это **текстовый файл**, в котором данные хранятся в виде **таблицы**, где каждая строка соответствует записи, а поля разделяются запятой (или другим разделителем, например `;`).

Пример `data.csv`:

```
Имя,Возраст,Город
Анна,18,Москва
Борис,20,СПб
Виктор,19,Казань
```

CSV-файлы широко используются для обмена данными между программами и базами данных.

---

### 2. Работа с CSV с помощью модуля `csv`

Python имеет стандартный модуль `csv` для чтения и записи CSV-файлов.

```python
import csv
```

---

### 3. Чтение CSV-файлов

**Чтение с помощью `csv.reader`**:

```python
with open("data.csv", "r", encoding="utf-8") as file:
    reader = csv.reader(file)  # создание объекта reader
    for row in reader:
        print(row)
```

Результат:

```
['Имя', 'Возраст', 'Город']
['Анна', '18', 'Москва']
...
```

**Чтение с заголовком с помощью `csv.DictReader`**:

```python
with open("data.csv", "r", encoding="utf-8") as file:
    reader = csv.DictReader(file)
    for row in reader:
        print(row["Имя"], row["Возраст"])
```

Результат:

```
Анна 18
Борис 20
```

---

### 4. Запись CSV-файлов

**Запись с помощью `csv.writer`**:

```python
with open("new_data.csv", "w", encoding="utf-8", newline="") as file:
    writer = csv.writer(file)
    writer.writerow(["Имя", "Возраст", "Город"])  # заголовок
    writer.writerow(["Мария", 21, "Киев"])
    writer.writerow(["Игорь", 22, "Минск"])
```

**Запись с помощью `csv.DictWriter`**:

```python
with open("new_data.csv", "w", encoding="utf-8", newline="") as file:
    fieldnames = ["Имя", "Возраст", "Город"]
    writer = csv.DictWriter(file, fieldnames=fieldnames)
    writer.writeheader()
    writer.writerow({"Имя": "Мария", "Возраст": 21, "Город": "Киев"})
```

---

### 5. Основные параметры модуля `csv`

* `delimiter` — символ-разделитель (по умолчанию `,`);
* `quotechar` — символ для заключения строк в кавычки (по умолчанию `"`);
* `newline=""` при открытии файла — предотвращает добавление пустых строк на Windows;
* `fieldnames` — список ключей для `DictWriter`.

---

### 6. Применение CSV-файлов

* хранение таблиц данных;
* обмен информацией между Excel, Google Sheets и Python;
* обработка больших данных построчно;
* подготовка данных для анализа и визуализации.

---

### 7. Вывод

CSV-файлы — это удобный формат для хранения табличных данных.
Модуль `csv` в Python позволяет безопасно читать и записывать CSV-файлы:

* `csv.reader` и `csv.writer` для работы с последовательностями;
* `csv.DictReader` и `csv.DictWriter` для работы с словарями и заголовками;
* поддержка разделителей, кавычек и автоматическое управление строками.

## Билет 13. Функции в Python. Параметры *args, **kwargs.

### 1. Понятие функции

Функция — это **именованный блок кода**, выполняющий определённое действие.
Функции позволяют **повторно использовать код**, делать его более структурированным и удобным для поддержки.

Создание функции в Python:

```python
def имя_функции(параметры):
    """Документация функции (docstring)"""
    блок_кода
    return значение  # необязательно
```

Пример:

```python
def greet(name):
    print(f"Привет, {name}!")
```

---

### 2. Вызов функции

Вызов функции выполняет её код:

```python
greet("Анна")  # Вывод: Привет, Анна!
```

Функции могут возвращать значения с помощью `return`:

```python
def add(a, b):
    return a + b

result = add(2, 3)  # 5
```

---

### 3. Параметры функции

Параметры бывают:

* **обязательные** — должны быть переданы при вызове;
* **необязательные с значением по умолчанию**:

```python
def greet(name="Гость"):
    print(f"Привет, {name}!")
```

---

### 4. Параметры `*args`

* Используется для передачи **нефиксированного числа позиционных аргументов**.
* В функции `*args` собирает все переданные позиционные аргументы в **кортеж**.

Пример:

```python
def add_all(*args):
    total = 0
    for num in args:
        total += num
    return total

print(add_all(1, 2, 3, 4))  # 10
```

---

### 5. Параметры `**kwargs`

* Используется для передачи **нефиксированного числа именованных аргументов**.
* В функции `**kwargs` собирает их в **словарь**.

Пример:

```python
def print_info(**kwargs):
    for key, value in kwargs.items():
        print(f"{key}: {value}")

print_info(name="Анна", age=18, city="Москва")
```

Результат:

```
name: Анна
age: 18
city: Москва
```

---

### 6. Одновременное использование `*args` и `**kwargs`

```python
def demo(a, *args, **kwargs):
    print("a:", a)
    print("args:", args)
    print("kwargs:", kwargs)

demo(1, 2, 3, x=10, y=20)
```

Результат:

```
a: 1
args: (2, 3)
kwargs: {'x': 10, 'y': 20}
```

> Важно: порядок параметров в определении функции — **обычные, *args, **kwargs**.

---

### 7. Применение

* `*args` удобно использовать, когда количество позиционных аргументов заранее неизвестно;
* `**kwargs` удобно использовать для передачи параметров конфигурации, настроек или дополнительных именованных аргументов;
* Позволяет создавать **гибкие и универсальные функции**.

---

### 8. Вывод

Функции в Python — это основа структурированного программирования.
Параметры `*args` и `**kwargs` делают функции **гибкими**, позволяя работать с любым количеством аргументов, как позиционных, так и именованных.
Это особенно полезно при создании библиотек, API и универсальных инструментов.

## Билет 14. Функции в Python. Lambda-функции.

### 1. Понятие функции

Функция — это **именованный блок кода**, который выполняет определённое действие и может возвращать результат.
Создание обычной функции:

```python
def add(a, b):
    return a + b

print(add(2, 3))  # 5
```

Функции позволяют **структурировать код**, использовать повторно блоки кода и облегчать чтение программы.

---

### 2. Lambda-функции

Lambda-функции — это **анонимные (безымянные) функции**, создаваемые с помощью ключевого слова `lambda`.
Они предназначены для **коротких одноразовых функций**, которые используются на месте, например, в качестве аргументов другой функции.

Синтаксис:

```python
lambda аргументы: выражение
```

Пример:

```python
f = lambda x, y: x + y
print(f(2, 3))  # 5
```

> Lambda-функция всегда возвращает результат выражения, **нет необходимости писать `return`**.

---

### 3. Применение lambda-функций

1. **Встроенные функции высшего порядка**, такие как `map`, `filter`, `sorted`:

* `map` — применяет функцию ко всем элементам последовательности:

```python
nums = [1, 2, 3, 4]
squared = list(map(lambda x: x**2, nums))
print(squared)  # [1, 4, 9, 16]
```

* `filter` — фильтрует элементы по условию:

```python
nums = [1, 2, 3, 4, 5]
even = list(filter(lambda x: x % 2 == 0, nums))
print(even)  # [2, 4]
```

* `sorted` — сортировка с ключом:

```python
data = [("Анна", 18), ("Борис", 20)]
sorted_data = sorted(data, key=lambda x: x[1])
print(sorted_data)  # [('Анна', 18), ('Борис', 20)]
```

---

### 4. Отличия обычной функции и lambda

| Характеристика | Обычная функция                     | Lambda-функция                                        |
| -------------- | ----------------------------------- | ----------------------------------------------------- |
| Имя            | Обязательно (можно присвоить)       | Необязательно, часто анонимная                        |
| Тело функции   | Может содержать несколько выражений | Одно выражение                                        |
| Return         | Явный `return`                      | Возвращает результат автоматически                    |
| Применение     | Любое                               | Чаще для коротких функций в аргументах других функций |

---

### 5. Особенности использования

* Lambda-функции лучше использовать для **простых одноразовых задач**;
* Для сложной логики лучше определять обычную функцию с `def`;
* Lambda-функции часто применяются в сочетании с `map`, `filter`, `reduce` и при сортировке.

---

### 6. Вывод

Lambda-функции в Python — это компактный способ создания **анонимных функций**, когда требуется одно выражение.
Они делают код кратким и удобным для передачи функций как аргументов, особенно при работе с коллекциями и функциями высшего порядка.
## Билет 15. Основы ООП в Python.

### 1. Понятие ООП

ООП (Объектно-ориентированное программирование) — это подход к программированию, при котором **программа строится на объектах**, которые объединяют данные и методы для их обработки.

Основные принципы ООП:

1. **Классы и объекты** — классы задают структуру и поведение, объекты — экземпляры классов.
2. **Инкапсуляция** — скрытие внутренней реализации объекта.
3. **Наследование** — создание новых классов на основе существующих.
4. **Полиморфизм** — возможность объектов разных классов иметь одинаковый интерфейс.

---

### 2. Классы и объекты

**Класс** — это шаблон или тип объекта.
**Объект** — это конкретный экземпляр класса.

Пример:

```python
class Person:
    def __init__(self, name, age):
        self.name = name  # атрибут
        self.age = age    # атрибут

    def greet(self):      # метод
        print(f"Привет, меня зовут {self.name}, мне {self.age} лет")

# Создание объекта
p1 = Person("Анна", 18)
p1.greet()  # Привет, меня зовут Анна, мне 18 лет
```

* `self` — ссылка на текущий объект;
* `__init__` — конструктор класса, вызывается при создании объекта.

---

### 3. Атрибуты и методы

* **Атрибуты** — данные объекта (например, `name`, `age`).
* **Методы** — функции, которые определены внутри класса и работают с объектом (например, `greet()`).

Пример доступа:

```python
print(p1.name)   # Анна
p1.age = 19      # изменение атрибута
```

---

### 4. Наследование

Наследование позволяет **создать новый класс на основе существующего** и расширять его функциональность.

Пример:

```python
class Student(Person):
    def __init__(self, name, age, grade):
        super().__init__(name, age)  # вызов конструктора родителя
        self.grade = grade

    def study(self):
        print(f"{self.name} учится в классе {self.grade}")

s1 = Student("Борис", 20, 11)
s1.greet()  # Привет, меня зовут Борис, мне 20 лет
s1.study()  # Борис учится в классе 11
```

---

### 5. Полиморфизм

Полиморфизм позволяет **использовать одинаковый интерфейс для разных объектов**:

```python
class Teacher(Person):
    def greet(self):
        print(f"Здравствуйте, я преподаватель {self.name}")

people = [Student("Анна", 18, 10), Teacher("Игорь", 35)]
for person in people:
    person.greet()  # вызывается соответствующий метод для каждого объекта
```

---

### 6. Инкапсуляция

Скрытие данных от внешнего доступа достигается с помощью:

* `_attr` — защищённый атрибут (рекомендация не использовать вне класса)
* `__attr` — приватный атрибут (доступ через имя `_ClassName__attr`)

Пример:

```python
class BankAccount:
    def __init__(self, balance):
        self.__balance = balance  # приватный атрибут

    def deposit(self, amount):
        self.__balance += amount

    def get_balance(self):
        return self.__balance

account = BankAccount(1000)
account.deposit(500)
print(account.get_balance())  # 1500
```

---

### 7. Вывод

Основы ООП в Python включают:

* создание **классов и объектов**;
* работу с **атрибутами и методами**;
* использование **наследования и полиморфизма**;
* **инкапсуляцию** данных для защиты внутреннего состояния объекта.

ООП позволяет создавать **структурированные, модульные и легко поддерживаемые программы**.
## Билет 16. «Волшебные» методы в ООП.
### 1. Понятие «волшебных» методов

В Python существуют специальные методы, которые называются **«волшебными» (magic или dunder methods)**, так как их имена начинаются и заканчиваются двойным подчёркиванием: `__init__`, `__str__`, `__add__` и т.д.

Они позволяют:

* переопределять стандартное поведение объектов;
* реализовывать операции с объектами как с встроенными типами;
* управлять созданием, отображением и арифметикой объектов.

---

### 2. Основные «волшебные» методы

1. **Конструктор и инициализация объекта**

```python
class Person:
    def __init__(self, name, age):
        self.name = name
        self.age = age
```

* `__init__` вызывается при создании объекта и инициализирует его атрибуты.

2. **Представление объекта**

```python
class Person:
    def __str__(self):
        return f"{self.name}, {self.age} лет"

p = Person("Анна", 18)
print(p)  # Анна, 18 лет
```

* `__str__` — строковое представление объекта для пользователя.
* `__repr__` — строковое представление для разработчика (например, в консоли).

3. **Арифметические операции**

```python
class Vector:
    def __init__(self, x, y):
        self.x = x
        self.y = y

    def __add__(self, other):
        return Vector(self.x + other.x, self.y + other.y)

v1 = Vector(2, 3)
v2 = Vector(1, 1)
v3 = v1 + v2  # использует __add__
print(v3.x, v3.y)  # 3 4
```

4. **Сравнение объектов**

```python
class Person:
    def __init__(self, age):
        self.age = age

    def __lt__(self, other):  # <
        return self.age < other.age

p1 = Person(18)
p2 = Person(20)
print(p1 < p2)  # True
```

* Другие методы сравнения: `__eq__`, `__le__`, `__gt__`, `__ge__`.

5. **Доступ к элементам**

```python
class MyList:
    def __init__(self, data):
        self.data = data

    def __getitem__(self, index):
        return self.data[index]

lst = MyList([1,2,3])
print(lst[1])  # 2
```

* `__setitem__` и `__delitem__` позволяют изменять и удалять элементы по индексу.

6. **Вызов объекта как функции**

```python
class Counter:
    def __init__(self):
        self.count = 0

    def __call__(self):
        self.count += 1
        return self.count

c = Counter()
print(c())  # 1
print(c())  # 2
```

---

### 3. Применение «волшебных» методов

* Создание **наших типов данных**, которые ведут себя как встроенные;
* Переопределение операций: сложение, сравнение, доступ по индексу;
* Улучшение **читабельности и удобства** работы с объектами;
* Создание объектов, которые можно использовать как функции, контейнеры или числа.

---

### 4. Вывод

«Волшебные» методы — это механизм Python для **настройки поведения объектов**.
С их помощью можно:

* управлять созданием (`__init__`),
* выводом (`__str__`, `__repr__`),
* арифметикой (`__add__`, `__sub__`),
* сравнением (`__lt__`, `__eq__`) и
* доступом к элементам (`__getitem__`, `__setitem__`).

Это делает объекты Python **гибкими, «живыми» и удобными** для программирования.
## Билет 17. Списочные выражения.

### 1. Понятие списочных выражений

Списочные выражения — это **короткий и удобный способ создавать списки** на основе существующих последовательностей или условий.
Они позволяют **сократить код**, делая его более читаемым и «питоничным».

Общий синтаксис:

```python
[выражение for элемент in последовательность if условие]
```

* `выражение` — значение, которое попадёт в новый список;
* `for элемент in последовательность` — перебор элементов исходной последовательности;
* `if условие` — необязательная фильтрация элементов.

---

### 2. Примеры списочных выражений

1. **Создание списка квадратов чисел**:

```python
squares = [x**2 for x in range(1, 6)]
print(squares)  # [1, 4, 9, 16, 25]
```

2. **Фильтрация элементов**:

```python
even_numbers = [x for x in range(1, 11) if x % 2 == 0]
print(even_numbers)  # [2, 4, 6, 8, 10]
```

3. **Изменение элементов при создании нового списка**:

```python
words = ["apple", "banana", "cherry"]
upper_words = [w.upper() for w in words]
print(upper_words)  # ['APPLE', 'BANANA', 'CHERRY']
```

4. **Вложенные циклы**:

```python
pairs = [(x, y) for x in [1,2,3] for y in [4,5]]
print(pairs)  # [(1,4),(1,5),(2,4),(2,5),(3,4),(3,5)]
```

---

### 3. Отличие списочных выражений от обычного цикла

**Обычный цикл:**

```python
squares = []
for x in range(1, 6):
    squares.append(x**2)
```

**Списочное выражение:**

```python
squares = [x**2 for x in range(1, 6)]
```

* Короче и компактнее;
* Можно добавлять условия и вложенные циклы;
* Часто быстрее за счёт оптимизации интерпретатором Python.

---

### 4. Расширенные возможности

* **С вложенным условием**:

```python
numbers = [x for x in range(1, 21) if x % 2 == 0 if x % 3 == 0]
print(numbers)  # [6, 12, 18]
```

* **Использование функций**:

```python
def f(x):
    return x**2

squares = [f(x) for x in range(1, 6)]
```

* **Генераторы для памяти** — похожи на списочные выражения, но возвращают элементы по одному (`()`) вместо полного списка:

```python
gen = (x**2 for x in range(1, 6))
```

---

### 5. Применение

Списочные выражения используют для:

* быстрого создания списков;
* фильтрации и преобразования данных;
* генерации матриц, пар, комбинаций;
* сокращения и упрощения кода.

---

### 6. Вывод

Списочные выражения — мощный инструмент Python, который позволяет **создавать списки компактно, читаемо и эффективно**, объединяя цикл, условие и преобразование элементов в одну конструкцию.

## Билет 18. Исключения в Python. 
### 1. Понятие исключений

Исключение — это **ошибка, которая возникает во время выполнения программы (runtime error)**.
Когда возникает исключение, выполнение программы **прерывается**, если его не обработать.

Примеры исключений:

* `ZeroDivisionError` — деление на ноль;
* `IndexError` — выход за пределы списка;
* `KeyError` — доступ к несуществующему ключу словаря;
* `ValueError` — неверное значение;
* `TypeError` — несоответствие типов.

---

### 2. Обработка исключений

Для обработки ошибок в Python используется конструкция **`try-except`**:

```python
try:
    # код, который может вызвать ошибку
    x = 10 / 0
except ZeroDivisionError:
    # действия при возникновении ошибки
    print("Деление на ноль невозможно")
```

* Если исключение возникло, блок `except` выполнится;
* Если ошибок нет, блок `except` пропускается.

---

### 3. Несколько исключений

Можно обрабатывать разные ошибки разными блоками `except`:

```python
try:
    x = int(input("Введите число: "))
    y = 10 / x
except ValueError:
    print("Нужно ввести число")
except ZeroDivisionError:
    print("Деление на ноль запрещено")
```

---

### 4. Блок `else` и `finally`

* **`else`** выполняется, если **исключение не возникло**:

```python
try:
    x = int(input("Введите число: "))
except ValueError:
    print("Ошибка")
else:
    print("Вы ввели число:", x)
```

* **`finally`** выполняется **в любом случае**, независимо от ошибки:

```python
try:
    f = open("file.txt", "r")
except FileNotFoundError:
    print("Файл не найден")
finally:
    print("Окончание обработки")
```

---

### 5. Генерация собственных исключений

С помощью `raise` можно **создать своё исключение**:

```python
x = -5
if x < 0:
    raise ValueError("x не может быть отрицательным")
```

---

### 6. Применение исключений

* Обеспечение **безопасного выполнения программы**;
* Предотвращение аварийного завершения;
* Ловля ошибок ввода/вывода, работы с файлами, сети;


### 3. Разбор структуры

1. **`<!DOCTYPE html>`**

* Объявляет тип документа как HTML5;
* Не является тегом, но обязателен для корректного отображения в браузере.

2. **`<html lang="ru">`**

* Корневой тег документа;
* Атрибут `lang` указывает язык страницы.

3. **`<head>`**

* Содержит **метаинформацию о документе**;
* Включает:

  * `<meta charset="UTF-8">` — кодировка страницы;
  * `<meta name="viewport">` — настройка адаптивного отображения на мобильных устройствах;
  * `<title>` — заголовок страницы (отображается в вкладке браузера);
  * ссылки на CSS и скрипты.

4. **`<body>`**

* Основное содержимое страницы: текст, изображения, ссылки, таблицы, формы, мультимедиа;
* Всё, что видит пользователь.

* Абзацы: `<p>`

```html
    <li>Элемент 1</li>
    <li>Элемент 2</li>
</ul>
```

* Встроенные формы с расширенными типами: `email`, `number`, `date`

HTML5-документ имеет **четкую иерархическую структуру**:

### 1. Что такое CSS

CSS (Cascading Style Sheets — каскадные таблицы стилей) — это язык **оформления веб-страниц**, который отвечает за внешний вид элементов:

* цвет текста и фона,

### 2. Способы совмещения HTML и CSS

Есть **три основных способа добавления CSS** к HTML-документу:

#### a) Встроенные стили (inline)

* Стиль задаётся **непосредственно в теге** через атрибут `style`.

```html
<p style="color: red; font-size: 20px;">Привет!</p>
```

* Используется для единичных элементов, но не рекомендуется для больших проектов.

#### b) Внутренние стили (internal)

* CSS пишется внутри тега `<style>` в `<head>` документа.

```html
<head>
  <style>
    p {
      color: blue;
      font-size: 18px;
    }
    h1 {
      text-align: center;
    }
  </style>
</head>
<body>
  <h1>Заголовок</h1>
  <p>Текст абзаца</p>
</body>
```

* Подходит для одной страницы, удобно тестировать стили.

#### c) Внешние стили (external)

* CSS хранится в отдельном файле `.css`, подключаемом через тег `<link>`.

```html
<head>
  <link rel="stylesheet" href="style.css">
</head>
```

`style.css`:

```css
body {
  background-color: #f0f0f0;
}

p {
  color: green;
  font-size: 16px;
}
```

* Рекомендуется для больших сайтов, так как стили можно использовать на нескольких страницах.


**Тема: Основы языка SQL**

---

### 1. Что такое SQL

SQL (Structured Query Language — язык структурированных запросов) — это **язык для работы с базами данных (БД)**.
С помощью SQL можно:

* создавать базы данных и таблицы;
* добавлять, изменять и удалять данные;
* выполнять выборку и сортировку;
* фильтровать данные по условиям.

SQL используется в большинстве СУБД (MySQL, PostgreSQL, SQLite, Oracle, MS SQL Server).

---

### 2. Основные команды SQL

SQL команды делятся на несколько групп:

#### a) DDL (Data Definition Language) — создание структуры

* `CREATE DATABASE имя_базы;` — создать базу данных
* `CREATE TABLE имя_таблицы (...);` — создать таблицу
* `ALTER TABLE имя_таблицы ...;` — изменить таблицу
* `DROP TABLE имя_таблицы;` — удалить таблицу

Пример:

```sql
CREATE TABLE Students (
    id INT PRIMARY KEY,
    name VARCHAR(50),
    age INT
);
```

---

#### b) DML (Data Manipulation Language) — работа с данными

* `INSERT INTO` — добавление данных
* `UPDATE` — обновление данных
* `DELETE` — удаление данных

Примеры:

```sql
INSERT INTO Students (id, name, age) VALUES (1, 'Анна', 18);
UPDATE Students SET age = 19 WHERE name = 'Анна';
DELETE FROM Students WHERE id = 1;
```

---

#### c) DQL (Data Query Language) — выборка данных

* `SELECT` — извлечение данных из таблиц
* `WHERE` — фильтрация
* `ORDER BY` — сортировка
* `LIMIT` — ограничение количества строк

Пример:

```sql
SELECT name, age FROM Students WHERE age > 18 ORDER BY name;
```

---

### 3. Типы данных в SQL

* `INT` — целые числа
* `VARCHAR(n)` — строки длиной до n символов
* `DATE` — дата
* `FLOAT` / `DECIMAL` — числа с плавающей точкой
* `BOOLEAN` — логические значения

---

### 4. Основные принципы SQL

* SQL **реляционный** — данные хранятся в таблицах, связанные между собой через ключи.
* Команды SQL обычно **независимы от языка программирования**.
* SQL-запросы позволяют **быстро получать и изменять данные**.

---

### 5. Вывод

SQL — это основной инструмент для работы с базами данных:

* создание таблиц и баз данных;
* добавление, изменение и удаление данных;
* выборка, фильтрация и сортировка информации.

Правильное использование SQL позволяет **организовывать, хранить и анализировать данные эффективно и безопасно**.

### 1. Что такое SQLite

Особенности:

* Не требует отдельного сервера;

---

### 2. Подключение к базе данных

```python
import sqlite3

# подключение к базе (файл создается автоматически, если его нет)
conn = sqlite3.connect("my_database.db")

# создание курсора для выполнения запросов
cursor = conn.cursor()
```

* `conn` — объект соединения с базой данных;
* `cursor` — объект для выполнения SQL-запросов.

---

### 3. Создание таблицы

```python
cursor.execute("""
CREATE TABLE IF NOT EXISTS Students (
    id INTEGER PRIMARY KEY,
    name TEXT,
    age INTEGER
)
""")
conn.commit()  # сохраняет изменения
```

* `IF NOT EXISTS` — проверяет, существует ли таблица;
* `PRIMARY KEY` — уникальный идентификатор записи.

---

### 4. Добавление данных

```python
cursor.execute("INSERT INTO Students (name, age) VALUES (?, ?)", ("Анна", 18))
```

* `?` — плейсхолдер для безопасной передачи данных;
* `commit()` — сохраняет изменения в базе.

---

### 5. Чтение данных

```python
cursor.execute("SELECT * FROM Students")
rows = cursor.fetchall()  # возвращает список всех строк
for row in rows:
```

* `fetchall()` — получает все строки;
* `fetchone()` — получает одну строку;
* `fetchmany(n)` — получает n строк.

---

### 6. Обновление и удаление данных

**Обновление:**

```python
cursor.execute("UPDATE Students SET age = ? WHERE name = ?", (19, "Анна"))

```

**Удаление:**

```python
cursor.execute("DELETE FROM Students WHERE name = ?", ("Анна",))
conn.commit()
```

### 7. Закрытие соединения

```python
conn.close()
```

* Закрытие соединения важно для освобождения ресурсов.

## Билет 24. Шаблоны. Синтаксис.  
### 1. Что такое шаблон в Django

В Django шаблон — это **HTML-файл с встроенным синтаксисом шаблонного языка Django (Django Template Language, DTL)**, который используется для динамического формирования страниц веб-приложений.

Цели шаблонов:

* отделить **логику приложения** (Python) от **отображения** (HTML);
* легко подставлять данные из базы и переменные в HTML;
* создавать повторно используемые страницы или фрагменты (например, заголовки, меню).

---

### 2. Расположение шаблонов

* Обычно шаблоны хранятся в папке `templates` внутри приложения или проекта:

```
myproject/
├─ myapp/
│  ├─ templates/
│  │  └─ myapp/
│  │      └─ index.html
```

* Django ищет шаблоны в `templates` по указанным в `settings.py` путям (`TEMPLATES['DIRS']`).

---

### 3. Синтаксис шаблонов Django

#### a) Вставка переменных

```html
<p>Привет, {{ user_name }}!</p>
```

* `{{ variable }}` — вставка значения из контекста, переданного из представления (view).

#### b) Условные конструкции

```html
{% if age >= 18 %}
<p>Вы совершеннолетний</p>
{% else %}
<p>Вы несовершеннолетний</p>
{% endif %}
```

* `{% %}` — управляющие конструкции (условия, циклы, блоки).

#### c) Циклы

```html
<ul>
{% for student in students %}
    <li>{{ student.name }} — {{ student.age }} лет</li>
{% empty %}
    <li>Список студентов пуст</li>
{% endfor %}
</ul>
```

* `{% for %}` перебирает список объектов;
* `{% empty %}` срабатывает, если список пуст.

#### d) Фильтры

```html
<p>{{ text|upper }}</p>  <!-- вывод текста заглавными буквами -->
<p>{{ date|date:"d.m.Y" }}</p>  <!-- форматирование даты -->
```

* Фильтры изменяют отображаемые данные (`upper`, `lower`, `date`, `default`, `length` и др.).

#### e) Комментарии

```html
{# Это комментарий Django, не отображается на странице #}
```

---

### 4. Использование шаблонов в представлениях (views)

```python
from django.shortcuts import render

def index(request):
    context = {
        "user_name": "Анна",
        "age": 18,
        "students": [{"name": "Борис", "age": 20}, {"name": "Виктор", "age": 19}]
    }
    return render(request, "myapp/index.html", context)
```

* `render(request, template_name, context)` — функция, которая связывает **шаблон** с **данными**;
* `context` — словарь, передающий переменные в шаблон.

---

### 5. Блоки и наследование шаблонов

Django позволяет **создавать базовые шаблоны** и расширять их для разных страниц:

**base.html**:

```html
<!DOCTYPE html>
<html>
<head>
    <title>{% block title %}Мой сайт{% endblock %}</title>
</head>
<body>
    <header>Меню сайта</header>
    <main>{% block content %}{% endblock %}</main>
    <footer>© 2026</footer>
</body>
</html>
```

**index.html**:

```html
{% extends "base.html" %}

{% block title %}Главная{% endblock %}

{% block content %}
<h1>Добро пожаловать!</h1>
<p>Привет, {{ user_name }}!</p>
{% endblock %}
```

* `{% extends %}` — наследование базового шаблона;
* `{% block %}` — области, которые можно переопределять.

---

### 6. Вывод

Шаблоны в Django:

* разделяют **логику и представление**;
* используют **переменные, циклы, условия, фильтры**;
* поддерживают **наследование и переиспользование** базовых шаблонов;
* упрощают создание динамических и поддерживаемых веб-страниц.
## Билет 25. Шаблоны. Фильтры.
### 1. Что такое фильтры в шаблонах Django

Фильтры — это **специальные инструменты Django Template Language**, которые позволяют **изменять или форматировать значения переменных при их выводе в шаблоне**.

* Используются внутри двойных фигурных скобок `{{ }}`.
* Позволяют: изменять регистр текста, форматировать даты, округлять числа, задавать значения по умолчанию и многое другое.

---

### 2. Синтаксис фильтров

```html
{{ variable|filter_name }}
```

* `variable` — переменная из контекста шаблона;
* `filter_name` — имя фильтра.

Можно применять **несколько фильтров подряд**:

```html
{{ variable|filter1|filter2 }}
```

---

### 3. Примеры основных фильтров

1. **Работа с текстом**

```html
{{ "hello world"|upper }}  <!-- HELLO WORLD -->
{{ "HELLO WORLD"|lower }}  <!-- hello world -->
{{ "hello world"|title }}  <!-- Hello World -->
```

2. **Фильтры для чисел**

```html
{{ 3.14159|floatformat:2 }}  <!-- 3.14 -->
```

3. **Фильтры для даты и времени**

```html
{{ today|date:"d.m.Y" }}  <!-- 18.01.2026 -->
{{ today|time:"H:i" }}    <!-- 14:30 -->
```

4. **Значение по умолчанию**

```html
{{ username|default:"Гость" }}
```

5. **Работа со списками**

```html
{{ my_list|length }}   <!-- количество элементов списка -->
{{ my_list|join:", " }} <!-- объединение элементов через запятую -->
```

6. **Обрезка текста**

```html
{{ text|truncatechars:20 }}  <!-- ограничение текста 20 символами -->
```

---

### 4. Применение фильтров

* Форматирование данных перед отображением без изменения их в Python-коде;
* Удобно для отображения дат, чисел и текста в нужном виде;
* Делает шаблоны более динамичными и гибкими;
* Поддержка **кастомных фильтров**: можно создавать свои фильтры для специфических задач.

Пример кастомного фильтра в `templatetags/my_filters.py`:

```python
from django import template
register = template.Library()

@register.filter
def double(value):
    return value * 2
```

Использование в шаблоне:

```html
{{ 5|double }}  <!-- 10 -->
```

---

### 5. Пример использования фильтров в шаблоне

```html
<p>Имя: {{ user.name|title }}</p>
<p>Возраст: {{ user.age }}</p>
<p>Дата регистрации: {{ user.date_joined|date:"d.m.Y" }}</p>
<p>Описание: {{ user.bio|truncatechars:50|default:"Нет информации" }}</p>
```

* Имя будет с заглавной буквы;
* Дата форматируется;
* Описание обрезается и задается значение по умолчанию, если пустое.

---

### 6. Вывод

Фильтры в шаблонах Django позволяют:

* изменять и форматировать данные **на стороне шаблона**;
* создавать более **динамичные и читабельные страницы**;
* комбинировать несколько фильтров и создавать **собственные**.

Использование фильтров делает шаблоны **гибкими, компактными и удобными для отображения данных**.
