# Скриптуем по полной

## 1. Что такое шебанг?

Шебанг — это первая строка скрипта, которая указывает, каким интерпретатором нужно выполнять файл. Она начинается с `#!` и позволяет системе понять, как запускать скрипт.

Пример:  
#!/bin/bash

## 2. Обязательно ли исполняемый файл должен иметь соответствующее расширение?

Нет, расширение не обязательно. В Linux важны права на исполнение и наличие шебанга. Файл можно запускать без расширения, если у него есть право `x` и корректно указан интерпретатор.

А вот и команда для добавления прав на исполнение:  
chmod +x script

## 3. Напишите скрипт, который выполнит автоматически действия из блока работы с файлами. Опишите set -euo pipefail
 
set -e — завершает скрипт при любой ошибке  
set -u — завершает скрипт при использовании неинициализированной переменной  
set -o pipefail — считает ошибкой сбой любой команды в конвейере  

Пример скрипта:

```bash
#!/bin/bash
set -euo pipefail

WORKDIR=/tmp/workdir

mkdir -p "$WORKDIR"
cd "$WORKDIR"

touch file1.txt file2.txt
echo "Hello Linux" > file1.txt
echo "Script works" > file2.txt

ls -l
cat file1.txt file2.txt
```
