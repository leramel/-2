# Скриптуем по полной
1. Что такое шебанг?
    Шебанг (shebang) — это последовательность символов #! в первой строке скрипта, которая указывает операционной системе, какой интерпретатор следует использовать для выполнения данного файла.
2. Обязательно ли исполняемый файл дожен иметь соотвествующее расширение?
    В Linux исполняемый файл не обязательно должен иметь определённое расширение. Его статус как исполняемого определяется правами доступа, а не названием файла.

3. Напишите скрипт который выполнит автоматически действия из блока работы с файлами. ( не забудьте включить set -euo pipefail для того что бы ваш скрипт было удобнее отлаживать. Опишите что включают эти флаги)

#!/bin/bash

set -euo pipefail

# Пример блока работы с файлами
# Создание файла
touch example.txt

# Запись данных в файл
echo "Hello, World!" > example.txt

# Проверка существования файла
if [ -f example.txt ]; then
    echo "Файл существует."
fi

# Чтение файла
cat example.txt

# Удаление файла
rm example.txt

-e: Скрипт завершится немедленно, если после любой из команд произойдёт ошибка.
-u: обрабатывает попытку использования необъявленных переменных как ошибку
-o pipefail: рекращает выполнение скрипта, даже если одна из частей конвейера (пайпа) завершилась ошибкой.
